Safety and production behavior
All nested resources bind owner and Job, with route-level synthetic HTTP checks.
Only visible allowlisted content enters repeatable-read source snapshots; custom
and custom_sections aliases both hide custom data. Contact/layout/hidden metadata
are omitted. Every new AI operation against stale source is blocked; history,
feedback, saved answers and non-AI practice actions remain readable/usable.
Source parents/content/visibility are locked until net/http WroteRequest confirms
actual body transmission, then unlocked before response wait. A 5-second dispatch
timer cancels a stalled connection/write; cleanup waits for call return. Redirects,
transparent body replay and SDK retries are disabled. Final publication rechecks
source atomically. Crash after durable send intent is conservatively ambiguous;
exactly-once external provider execution is not claimed. Two workers, operation
80s/provider 60s/lease 90s, fenced completion, at most three explicit attempts.
Telemetry contains operation identity/type/attempt/duration/outcome only.

Answers persist independently of AI feedback/quota. The final release admits
answers before persistence against a 120,000-byte lossless serialized summary
budget, reserving every future followup and skipped-answer metadata. Source input
is capped at 48,000 bytes; original question context at 24,000 bytes; followups at
2,048 bytes. No answer is truncated and drafts survive capacity rejection. Minimal
review inputs include question context and answers, omitting prior feedback and
timestamps. Migration 049 is new/never deployed: pre-fix synthetic rows create no
production backward-compatibility requirement. Every session accepted under the
final release contract remains summarizable.

Quota reservation shares the existing per-user advisory lock and allowance with
legacy AI endpoints. Interview enqueue/receipt/usage are atomic; retained retries
charge once. Known no-call failures refund unused charges, and retry reacquires
the same receipt atomically. During-call/ambiguous calls retain the single charge.
Legacy pending reservations expire after 120s, above the AI-only request deadline
of 90s; successful Record commits original match_score/resume_autofill_parse
categories idempotently. Failed commit leaves a recoverable pending receipt.
Redis fail-open cannot bypass PostgreSQL pending/enqueue guards.
Sensitive dialog content is excluded from PostHog capture/replay, and all AI/user
prose renders as escaped React text.
